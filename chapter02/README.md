# 第 2 章：智能体发展史

教程：[第二章 智能体发展史](https://hello-agents.datawhale.cc/#/./chapter2/%E7%AC%AC%E4%BA%8C%E7%AB%A0%20%E6%99%BA%E8%83%BD%E4%BD%93%E5%8F%91%E5%B1%95%E5%8F%B2)

## 本章学习方式

本章不采用“先读完整章，再统一做题”的方式。读到下面标明的暂停点时，先做对应的小练习，再继续阅读。

原则：

- 教程中的实践优先，额外练习只用于帮助理解眼前的概念。
- 每次练习控制在 5～20 分钟，避免打断阅读主线太久。
- 代码由学习者亲手输入和修改，遇到问题再共同调试。
- 本文件同时记录进度，完成一项后把 `[ ]` 改成 `[x]`。

## 穿插安排

### 阶段 1：符号主义与早期智能体

先阅读：

- 2.1 基于符号与逻辑的早期智能体
- 2.1.1 物理符号系统假说
- 2.1.2 专家系统
- 2.1.3 SHRDLU
- 2.1.4 符号主义面临的根本性挑战

读完 `2.1.4` 后暂停，完成一个约 5 分钟的小练习：

- [ ] 用自己的话区分“知识库”和“推理机”。
- [ ] 为一个生活场景写出两条 `IF 条件 THEN 结论/行动` 规则。
- [ ] 判断两条规则属于正向链思路还是反向链思路。
- [ ] 举出一个规则未覆盖、系统就无法正确处理的例子。

### 阶段 2：ELIZA 的原理

继续阅读：

- 2.2 构建基于规则的聊天机器人
- 2.2.1 ELIZA 的设计思想
- 2.2.2 模式匹配与文本替换

读完 `2.2.2` 后暂停，先不看完整实现，做正则匹配推演：

- [ ] 判断给定用户输入能否匹配某条规则。
- [ ] 写出完整匹配结果。
- [ ] 写出 `match.group(1)` 的结果。
- [ ] 解释捕获结果怎样被放进回复模板。

### 阶段 3：亲手实现迷你 ELIZA

阅读 `2.2.3 核心逻辑的实现`，并在本目录创建 `eliza.py`。不要一次复制全部代码，按下面顺序逐步完成：

- [ ] 编写并观察规则库。
- [ ] 编写代词转换函数。
- [ ] 编写 `respond()`。
- [ ] 加入 `while` 聊天循环。
- [ ] 每完成一个部分就运行一次。
- [ ] 故意输入规则无法妥善处理的话，记录它的表现。

届时从项目根目录运行：

```powershell
uv run python chapter02/eliza.py
```

### 阶段 4：立即改造 ELIZA

基础版本运行后立刻实践，不等到章末：

- [ ] 自己添加一条与“学习”有关的规则。
- [ ] 自己添加一条与“工作”有关的规则。
- [ ] 调整两条规则的先后顺序，观察匹配结果是否改变。
- [ ] 用自己的话说明规则系统为什么会越来越难维护。

暂时不加入上下文记忆；先理解无状态规则系统，再逐步增加状态。

### 阶段 5：心智社会与多智能体思想

阅读：

- 2.3 马文·明斯基的心智社会
- 2.3.1 对单一整体智能模型的反思
- 2.3.2 作为协作体的智能
- 2.3.3 对多智能体系统的理论启发

读完后暂停：

- [ ] 把“完成一次旅行规划”拆成 3～5 个专用小智能体。
- [ ] 写出每个小智能体只负责什么。
- [ ] 推演其中一个小智能体失效后，整体会发生什么。
- [ ] 说明这种协作结构的一个优点和一个缺点。

### 阶段 6：学习范式与现代智能体

阅读 2.4 时按小节做一分钟判断题：

- [ ] 2.4.1：说明联结主义的知识存在哪里。
- [ ] 2.4.2：为一个游戏指出状态、行动和奖励。
- [ ] 2.4.3：说明预训练如何缓解知识获取瓶颈。
- [ ] 2.4.4：将第一章 `first_agent.py` 的组件映射到历史上的思想流派。

映射时重点观察：

```text
LLM                   -> 联结主义与大规模预训练
提示词、输出协议、解析 -> 符号和规则
工具调用与环境反馈     -> 行动、观察与迭代
多个专用工具           -> 模块化协作
```

### 阶段 7：章末综合练习

不要求一次做完全部官方习题。本阶段优先选择：

- [ ] 扩展 ELIZA 的 3～5 条规则。
- [ ] 为 ELIZA 加入简单的姓名、职业或爱好记忆。
- [ ] 对比 ELIZA 与现代 LLM 对话系统的至少三个本质差异。
- [ ] 用超级马里奥的例子解释强化学习中的状态、行动和奖励。
- [ ] 比较三个时代会怎样设计“智能代码审查助手”。
