# 第 3 章：大语言模型基础

教程：[第三章 大语言模型基础](https://hello-agents.datawhale.cc/#/./chapter3/%E7%AC%AC%E4%B8%89%E7%AB%A0%20%E5%A4%A7%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B%E5%9F%BA%E7%A1%80)

## 本章目标

本章代码和数学内容较多，不一路读到底。每到一个暂停点，先用小实验把概念变成可观察的结果，再继续阅读。

学完后应当能够：

- 用通俗语言解释语言模型为什么是在“预测下一个 Token”。
- 说明 N-gram、RNN/LSTM 和 Transformer 分别解决了什么问题。
- 理解注意力、位置编码、因果掩码和 Decoder-Only 的作用。
- 实际比较不同提示方法的输出，并理解采样参数的作用。
- 观察一次简单的 BPE 合并过程。
- 理解模型选型、Token 成本和幻觉对 Agent 的影响；幻觉核查实验留待后续章节需要时再做。
