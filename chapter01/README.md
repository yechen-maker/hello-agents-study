# 第 1 章：初识智能体

## 本章真正要学会什么

读完文字不是完成。完成本章时，你应该能用自己的话解释并亲手写出下面这条循环：

```text
用户提出目标
    ↓
模型判断下一步行动
    ↓
程序执行工具
    ↓
把工具结果交还给模型
    ↓
模型继续行动或给出最终答案
```

这里的“智能体”不是一个神秘的新模型。最小版本可以理解为：

> 大语言模型 + 可调用的工具 + 一段反复执行的控制循环。

## 学习顺序

### 任务 1：Python 热身

打开 `warmup.py`，完成所有标有 `TODO` 的地方。先不要看教程参考代码。

运行练习：

```powershell
uv run python chapter01/warmup.py
```

运行检查器：

```powershell
uv run python chapter01/check_warmup.py
```

检查器全部通过后，再进入第一个 Agent。

### 任务 2：不使用 LLM 的工具调用

我们会先手动指定工具名和参数，弄懂“函数注册表”是什么。此时程序还不智能，但可以看清 Agent 的程序骨架。

### 任务 3：接入 LLM

让模型按 `Thought` 和 `Action` 格式选择工具。API 密钥只放在 `.env`，不要写进 Python 文件，也不要提交到 Git。

### 任务 4：完成行动循环

把模型输出解析为工具调用，将工具执行结果作为 `Observation` 追加到历史记录，直到模型输出 `Finish[...]`。

## 本章验收标准

- 能解释函数、参数、返回值、字典和异常分别是什么。
- 能说明普通聊天模型与 Agent 的区别。
- 能画出 `Thought → Action → Observation` 循环。
- 能亲手增加一个新工具，而不是复制整份示例。
- 遇到报错时，能指出错误类型、出错文件和行号。
