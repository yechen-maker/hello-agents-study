# 第 4 章：智能体经典范式构建

教程：[第四章 智能体经典范式构建](https://hello-agents.datawhale.cc/#/./chapter4/%E7%AC%AC%E5%9B%9B%E7%AB%A0%20%E6%99%BA%E8%83%BD%E4%BD%93%E7%BB%8F%E5%85%B8%E8%8C%83%E5%BC%8F%E6%9E%84%E5%BB%BA)

## 本章目标

在第一章的最小 Agent 循环基础上，逐步理解并实现三种组织“思考与行动”的方式：ReAct、Plan-and-Solve、Reflection。练习与教材穿插，不要求先读完整章再编码。

## 穿插安排

### 阶段 1：4.1 环境准备与基础 LLM 客户端

先读 `4.1.1`～`4.1.3`，暂停在客户端示例结束处。

- [ ] 对照第一章 `first_agent.py` 和第三章 `prompt_experiment.py`，找出已有的模型调用与 `.env` 配置，避免重复搭建。
- [ ] 画出 `messages` 从调用代码进入 LLM、再由流式 `chunk` 拼成字符串的路径。
- [ ] 再亲手写或整理本章共用的 LLM 客户端；先用最小输入验证，不急着启动 Agent。

教程写 `pip install openai python-dotenv`；本仓库继续用 `uv` 管理依赖，先检查 `pyproject.toml` 是否已有这两个包，缺少时再使用 `uv add 包名`。本章模型调用可走现有 API，不要求本地部署开源模型。配置从项目根目录 `.env` 读取。

**第一个暂停点：**读完 `4.1.3`，先告诉我 `messages` 和流式返回各是什么；我们再决定共用代码放在哪里。

### 阶段 2：4.2 ReAct

读完 `4.2.1` 工作流程后暂停：用第一章旅行助手画出一次 `Thought → Action → Observation`。指出新观察如何影响下一轮行动。

读 `4.2.2` 工具定义与 `4.2.3` Agent 实现时分两次动手：

- [ ] 先做一个可预测的本地工具（如计算器）和工具注册表，不依赖搜索 API 也能检查调度逻辑。
- [ ] 再让模型完成至少两轮“选择工具 → 读取观察 → 结束”的任务；记录原始输出、解析结果与终止原因。
- [ ] 读完 `4.2.4` 后，试着解释输出格式错误、工具错误和循环不终止分别怎么定位。

教材的搜索工具用 SerpApi；本章学习重点是工具接口与循环，可以复用第一章已有的搜索工具，不必为了相同概念再注册一个服务。实时事实任务仍须依据实际检索结果作答。

### 阶段 3：4.3 Plan-and-Solve

读完 `4.3.1`～`4.3.2` 后暂停：对教程的水果店题，自己先写出三步计划及各步所需输入，不让模型代算。

- [ ] 实现或模拟“先生成完整计划，再逐步执行”的最小流程。
- [ ] 每执行一步，把结果加入状态；指出下一步读到的是哪一条前序结果。
- [ ] 与 ReAct 比较：哪一种更容易根据新观察临时改变路线？

读完 `4.3.3`～`4.3.4` 后再做一次完整运行与复盘。

### 阶段 4：4.4 Reflection

先读 `4.4.1`～`4.4.2`，暂停并用纸面例子写出“初稿 → 反馈 → 修订稿”的记录结构。

- [ ] 用一个有明确验收标准的小任务体验反思循环，例如生成并检查求素数函数。
- [ ] 区分模型的自我评价与真正运行检查器得到的结果。
- [ ] 设置最大迭代次数；读完 `4.4.3`～`4.4.5` 后比较改进收益与额外模型调用成本。

这里研究的是 Reflection 范式，不补做第三章已决定跳过的独立“幻觉核查实验”。

### 阶段 5：4.5 小结与章末复盘

- [ ] 用一个具体任务分别说明三种范式的运行顺序、适用场景和成本。
- [ ] 从章末习题优先选“给 ReAct 加计算器工具”和“三种范式比较”；其余按兴趣选择。
- [ ] 跑通本章代码检查，再进行 Git 复盘与提交。

## 本章 Git 学习

沿用第三章的真实提交历史，重点亲手练习：

1. `git status --short`：确认本次有哪些文件变动。
2. `git diff` 与 `git diff --staged`：分别看未暂存和已暂存的修改。
3. `git add 具体文件`：只暂存一个阶段的成果。
4. `git commit -m "..."`：保存该阶段快照。
5. `git log --oneline` 与 `git show 提交编号`：回看做了什么。

本章产生的代码建议按范式分次提交；不要等到所有示例都写完才第一次提交。
