## 本章 Git 学习

沿用第三章的真实提交历史，重点亲手练习：

1. `git status --short`：确认本次有哪些文件变动。
2. `git diff` 与 `git diff --staged`：分别看未暂存和已暂存的修改。
3. `git add 具体文件`：只暂存一个阶段的成果。
4. `git commit -m "..."`：保存该阶段快照。
5. `git log --oneline` 与 `git show 提交编号`：回看做了什么。
