## 本章目标

把第四章手写的模型、工具、记忆与循环，映射到可视化平台的节点和配置上。**按教程顺序**了解 Coze、Dify、FastGPT、n8n；每到一个平台，只挑对今后开发有实际帮助、门槛和价格都合适的部分体验。不是四个平台的全功能打卡，也不预先指定唯一重点平台。

每个平台先看能否用免费额度或现有环境完成一个最小验证，再决定是否动手。若必须付费、部署成本高或只是重复已掌握的功能，记录原因后继续按教程顺序阅读；不为完成练习而购买套餐。平台界面和收费可能变化，实际操作前以官方页面和账号内的额度提示为准。
